Add `ClientAuth` (including RFC 10070 `secretJwt`/`privateKeyJwt`, name-bound `unwrap`, and `withPreparedRequest`), `Grant` (`authorizationCode`, `{ issuer, clientId }`-bound `fromTransaction`, `refreshToken`, `clientCredentials`, `make`, `TokenReceipt`/`TokenReceiptFromJson`, `parseTokens`), scoped `OAuth.Client` (`make`/`layer`, single-snapshot `prepareAuthorization`, `OAuth.authorize`, `exchangeRaw`/`exchange`, `revoke`), and `Oidc.authorize` in `@yielded/oauth`, and migrate `@yielded/auth` providers including Apple and Strava onto them.

BEHAVIOR CHANGE: Direct `@yielded/oauth` consumers must migrate from `OAuth.make({ metadata, authentication, timeoutMs })`, `client.codeGrant`/`refreshGrant`, and `OAuth.tokens` to `Discovery`, `ClientAuth`, `Grant`, and `OAuth.Client`; HTTP `5xx` responses now fail with `TransportFailed`. Across both `@yielded/oauth` and `@yielded/auth`, authorization URLs now omit `response_mode` for `"query"` (emitting `response_mode=form_post` only for `"form_post"`). In `@yielded/auth`, Strava token POSTs now route through `OAuth.Client`: HTTP `401` token responses and contradictory receipts combining token success fields with error indicators (on `200` or `400`) now report `OAuthUnavailable`, `client_id`/`client_secret` follow `grant_type` and `code`/`refresh_token`, and token/athlete requests add `Accept: application/json`, `;charset=UTF-8`, a 10-second token timeout, `credentials: "omit"`, `cache: "no-store"`, and disabled trace propagation (`b3`/`traceparent`). No stored-data reset is required.
